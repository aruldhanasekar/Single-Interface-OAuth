# OAuth Configuration

I started building V1 of **One-Auth** to simplify OAuth provider management for applications.

The goal is to provide **one interface for multiple OAuth providers**, such as Google and Microsoft, so applications don't need to integrate with each provider separately.

### Privacy & Data

* No unnecessary user data is shared.
* Only the following profile information can be shared:

  * Profile picture
  * Name
  * Email address
  * Phone number *(only if the user explicitly chooses to share it)*
* Users can see where they have signed up using One-Auth.

### Vision

**One-Auth — One Interface for Authentication.**
